🔌 Connections
Every link between VoiceGuard, the phone system and the CMS. Nothing here changes anything — it only checks whether each one is connected, and says what is missing when it isn't.
Press “Test everything”.

Credentials worth rotating

These appear in the CMS source and in the CSV export that is emailed out, so anyone who has ever had either also has these.
• Cardknox — the live payment gateway (the settings still call it Stripe)
• BulkVS — can order and delete your phone numbers
• Asterisk database — the phone system's own MySQL login
• Stripe — in AdminSettings, possibly unused now, rotate anyway
Also check Jobs/jobconfig.json on the CMS server — a scheduled export of whole tables (customers, personal info, payments, settings) is emailed to an outside address.

Card payments

Whether the two Cardknox keys have actually reached the running app. A setting saved in Azure does not take effect until the app restarts.
